云服务销售系统·安装说明
=====================================

声明：本源码采用AGPL3.0开源协议，二开必须继续开源发布，不得加密。


一、安装步骤
1.将本目录整体上传到服务器（推荐部署在网站根目录）。
2.将网站「运行目录」设置为public。
3.设置伪静态为：ThinkPHP 伪静态。
4.浏览器访问您的域名/安装/（或直接访问域名）按步骤完成数据库信息安装。
   -数据库表外部默认yun_（可在安装时自定义）。
5.安装完成后，请登录后台并「修改默认密码」。

（修改首次登录后请务必立即密码）
